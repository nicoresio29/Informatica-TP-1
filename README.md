## 📌 Descripción del Proyecto
Este proyecto integrador analiza la evolución tecnológica del desarrollo web (Frontend y Backend) y la integración de herramientas de Inteligencia Artificial en los flujos de trabajo de desarrollo y marketing digital durante el quinquenio **2021–2026**. 

A partir de datos cuantitativos sobre adopción de tecnologías, indicadores de productividad y normativas de ciberseguridad, se consolidaron informes de datos y se diseñó un sitio web interactivo y responsive desplegado en Netlify.

## 🛠️ Herramientas Utilizadas y Metodología

El desarrollo se realizó utilizando estrictamente el conjunto de herramientas autorizadas:

* **Perplexity AI:** Búsqueda, recopilación de datos estadísticos e investigación de normativas y tendencias del sector de software e IA.
* **Cuaderno Gemini (NotebookLM):** Síntesis, cruzamiento de datos y estructuración de los hallazgos para la elaboración de las planillas de cálculo y el informe escrito.
* **Claude / Gemini:** Análisis de la información y generación del código fuente unificado (`index.html` con CSS interno y Chart.js para visualizaciones).
* **Netlify:** Plataforma de alojamiento para el despliegue y publicación continua del sitio web.
* **GitHub:** Control de versiones, documentación transparente del proyecto en `README.md` y alojamiento del código fuente.

## 💻 Características del Sitio Web
* **Diseño Responsive & Dark Mode:** Interfaz moderna adaptada a dispositivos móviles y de escritorio.
